# PRODIGY_ML_04 – Hand Gesture Recognition

## Project Overview
Developed a Hand Gesture Recognition model using Convolutional Neural Networks (CNN) to identify and classify different hand gestures from images.

## Dataset
- Dataset: LeapGestRecog
- Source: Kaggle
- Classes: 10 hand gestures
- Image Size: 64 × 64
- Color Mode: Grayscale

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn
- CNN (Deep Learning)

## Model Architecture
- Convolutional Layers
- Max Pooling Layers
- Flatten Layer
- Dense Layer
- Dropout
- Softmax Output Layer

## Model Training
- Optimizer: Adam
- Loss Function: Sparse Categorical Crossentropy
- Epochs: 10
- Batch Size: 32

## Evaluation
Evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Project Files
- `Task_04_Hand_Gesture_Recognition.ipynb` – Jupyter Notebook
- `hand_gesture_model.keras` – Trained CNN Model
